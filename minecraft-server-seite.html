Unsere Server

AstralSMP besteht aus zwei Servern. Beide erreichst du über dieselbe Adresse.

SMP-Server

Ein Survival-Multiplayer im Stil bekannter YouTuber-SMPs, aber mit eigenen Features, Story und Community.

Event-Server

Regelmäßige Events, Minigames und Turniere. Hier gewinnst du Ruhm und Belohnungen.

Eigene Features

Eigene Features und Mechaniken, die du so auf keinem anderen Server findest.

Fair

Anti-Cheat und regelmäßige Backups. Alles ist frei spielbar, es gibt nichts zu kaufen.

So trittst du bei

In drei Schritten bist du auf dem Server.

  1. Minecraft starten
    Öffne Minecraft Java Edition.
  2. Server hinzufügen
    Mehrspieler → Server hinzufügen → die IP astralsmp.net eintragen.
  3. Regeln lesen und loslegen
    Schau kurz in die Regeln und tritt danach unserem Discord bei.

Regeln

Damit alle Spaß haben, gelten diese Regeln. Passe sie an deinen Server an.

  1. Leichte Beleidigungen sind erlaubt. Echtes Mobbing, Hass und Drohungen nicht.
  2. Griefing ist erlaubt. Du darfst fremde Bauten zerstören.
  3. Keine Hacks, Cheats oder unfairen Mods.
  4. Kein Spam und keine Werbung für andere Server.
  5. Den Anweisungen des Teams ist Folge zu leisten.
